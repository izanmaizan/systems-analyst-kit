# Checklist Panduan Pengguna

## Umum
- [ ] Halaman judul dan identitas aplikasi
- [ ] Daftar isi
- [ ] Kebutuhan perangkat dan peramban
- [ ] Istilah yang dipakai

## Bagian per peran
- [ ] Bagian pengunjung atau pengguna umum
- [ ] Bagian operator atau pengelola
- [ ] Bagian administrator

## Langkah per menu
- [ ] Tujuan menu
- [ ] Langkah bernomor
- [ ] Tangkapan layar tiap langkah penting
- [ ] Hasil yang diharapkan setelah langkah selesai

## Penanganan kendala
- [ ] Tabel gejala, penyebab, tindakan pengguna
- [ ] Kontak bantuan dan jam layanan
- [ ] Prosedur jika lupa sandi (tanpa menuliskan sandi)

## Pemeriksaan akhir
- [ ] Tidak ada tangkapan layar berisi data pasien, pegawai, atau kredensial
- [ ] Nomor halaman dan daftar gambar sesuai

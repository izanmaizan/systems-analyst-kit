# Checklist Dokumen Hasil Pengujian dan UAT

## Rencana pengujian
- [ ] Maksud dan ruang lingkup
- [ ] Lingkungan uji: perangkat, sistem operasi, peramban, versi runtime dan framework
- [ ] Kriteria kelulusan
- [ ] Cakupan kelompok pengujian (fungsional, antarmuka, integrasi, aksesibilitas, kinerja, keamanan)

## Tabel skenario
- [ ] Kolom: kode, skenario, data masukan, hasil harapan, hasil aktual, status
- [ ] Satu kode per kebutuhan fungsional dari KAK
- [ ] Hasil aktual apa adanya, bukan karangan
- [ ] Yang tidak dapat diuji ditandai beserta alasannya

## Ringkasan dan temuan
- [ ] Jumlah kasus, lulus, gagal
- [ ] Daftar temuan: lokasi berkas/baris kode, gejala, rekomendasi
- [ ] Status tindak lanjut dan pengujian ulang
- [ ] Lampiran bukti (tangkapan layar tanpa kredensial dan data pribadi)

## UAT
- [ ] Identitas pelaksanaan
- [ ] Daftar uji penerimaan
- [ ] Kolom hasil, tanggal, nama, NIP dikosongkan
- [ ] Kesimpulan uji penerimaan
- [ ] Lembar pengesahan

## Pemeriksaan akhir
- [ ] Tidak ada status LULUS tanpa bukti
- [ ] Tidak ada kredensial di tangkapan layar
- [ ] Nomor temuan unik dan bisa dilacak

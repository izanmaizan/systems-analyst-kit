# Checklist KAK / TOR

## Blok judul
- [ ] Nama pekerjaan, instansi, unit kerja, alamat aplikasi
- [ ] Tahun anggaran, nomor dokumen (titik-titik), tanggal

## Isi wajib
- [ ] Latar belakang: kondisi saat ini, masalah, alasan pekerjaan perlu dilakukan
- [ ] Dasar hukum dan kebijakan (undang-undang, peraturan, SOP internal)
- [ ] Maksud dan tujuan, dipisah dan terukur
- [ ] Indikator keluaran (output) dan hasil (outcome)
- [ ] Ruang lingkup pekerjaan
  - [ ] Lingkup yang dikerjakan
  - [ ] Lingkup yang tidak termasuk
- [ ] Spesifikasi teknis aplikasi
  - [ ] Arsitektur dan teknologi
  - [ ] Kebutuhan fungsional per modul
  - [ ] Kebutuhan nonfungsional (kinerja, keamanan, aksesibilitas, kompatibilitas)
  - [ ] Integrasi dengan sistem lain
- [ ] Jadwal pelaksanaan per minggu atau per tahap
- [ ] Kualifikasi tim pelaksana per peran
- [ ] Hak cipta dan kepemilikan hasil pekerjaan
- [ ] Estimasi anggaran biaya (nominal dikosongkan)
- [ ] Penutup dan lembar pengesahan

## Pemeriksaan akhir
- [ ] Tidak ada nominal, nama pejabat, atau NIP
- [ ] Setiap kebutuhan fungsional punya kode (F-01, F-02, ...)
- [ ] Setiap kebutuhan nonfungsional punya kode (NF-01, NF-02, ...)
- [ ] Konsisten dengan SDD dan tabel pengujian
